## How it Works

1. It asks the user for their name
2. It confirms the name - asking again if incorrect
3. It asks what drink they want
4. It asks how many of said drinks they want
5. They ask if you want the drinks to have extra milk or extra sugar
6. It creates the total
7. Asks if you want a random treat with that (6 options)
8. if you do want the random treat - it asks how many and adds to the total
9. asks if you want any food items
10. if yes, it adds some items to the random treat list, shows all the options and asks how many of the item would would like
11. shows your subtotal and asks for payment method
12. if contactless / apple pay - it shows 'tap here'
13. if cash, it adds £2 because i hate cash, then takes the payment
14. if hack club voucher, takes payment of nothing and gives items

## The 'Ann-Droid' Easter Egg

Inside of the code, if you type your name as:

- sue
- Sue
- sue sue sue
- Sue Sue Sue

... it will confirm your name, tell you the barista is called Linda and asks how much you weigh. This is a 100% very funny reference to the UK BBC show named 'Ann Droid' where the robot, Linda, asks a random person how much she weighs. Don't ask - but test it if you like!
